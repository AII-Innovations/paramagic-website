Privacy Policy

Paramagic Backup Manager

Effective November 19, 2026

Paramagic Backup Manager is an administrative tool intended to help authorized operators create, store, and manage backups of software applications and their associated data. This policy explains how the tool is intended to use information and Google Drive permissions. Backup automation is being configured and may not yet be active.

Information handled

Depending on the applications selected for backup, backup files may contain application configuration, database records, and uploaded files. Such backups may include personal information entered into the underlying applications. Access to backup data should be limited to authorized administrators.

Google Drive access

When an authorized operator connects a Google account, Paramagic Backup Manager requests permission to create and manage files it uses in Google Drive. This access is intended solely to store, retrieve, organize, and delete backup files as directed by the operator or an authorized backup schedule. The tool is not intended to read unrelated files in the operator’s Google Drive.

Storage and sharing

Backups stored in Google Drive are subject to the connected Google account’s storage, access controls, and sharing settings. Paramagic does not intend to sell backup data or use it for advertising. Backup data may be processed by infrastructure providers needed to perform backup and storage operations.

Retention and deletion

Backup retention will depend on the schedule and retention settings configured for each application. Authorized administrators may delete stored backup files. Deleting a backup does not necessarily delete the original application data, and deleting original application data does not automatically delete an existing backup.

Security

Access to backup functions should be restricted to authorized operators. No storage or transmission system can guarantee absolute security. Backup processes and access controls should be tested and reviewed before relying on them for disaster recovery.

Revoking Google access

You can revoke Paramagic Backup Manager’s Google account access through your Google Account connections settings. Revoking access stops future authorized Drive operations but does not automatically delete backup files already stored in Drive.

Contact

For privacy questions or requests related to Paramagic Backup Manager, contact paramagic.apps@gmail.com.

Changes

This policy may be updated as the backup system’s functionality, storage providers, or operating practices change. The effective date above will be updated when material revisions are made.
